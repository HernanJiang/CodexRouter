# CodexRouter Theoretical Unix Build

This package is a theoretical CodexRouter build for macOS or Linux.

It has **not** been tested on a real macOS or Linux machine.

## What this binary does

The included `CodexRouter` binary is a theoretical placeholder. It prints a short notice and exits. It does not start the Windows desktop console, PostgreSQL, Redis, Sub2API, or the production router runtime.

The current supported runtime is **Windows 10/11 x64**.

## Why it exists

CodexRouter 1.7.4 publishes these packages so contributors can inspect, rebuild, and help verify non-Windows targets. The full GUI, Credential Manager integration, portable PostgreSQL/Redis/Sub2API payload, and installer wizard remain Windows-only in this release.
